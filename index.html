Game Help

Game Rules

Click nodes to change numbers, the goal is to make all nodes have the same number.

When you click a node, its number and adjacent nodes' numbers will change.

Game Modes

Pe Mode: Periodic boundary - The first node's neighbors are the second and last nodes

Fix Mode: Fixed boundary - Edge nodes only have one neighbor

Difficulty Levels

Easy: Fewer nodes and simpler initial configurations

Medium: Balanced difficulty

Hard: More nodes and more complex initial configurations
